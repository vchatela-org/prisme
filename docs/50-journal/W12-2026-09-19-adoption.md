### The shape that was decided before any code was written

Candidate discovery is a **scan**, not a live query. `prisme-sync adopt` reads both external tools,
resolves identity, and writes the result into `adoption_candidate` — a mirror of the last scan,
level-triggered, fully replaced each run. Decisions live elsewhere (`entity_link`,
`adoption_ignore`) and are never overwritten by a scan. The queue UI reads the mirror, so opening a
page never touches an external API.

Three tables, one decision each:

| Table | Holds | Written by |
|---|---|---|
| `adoption_candidate` | the last scan's unresolved candidates + proposals | the scan, wholesale |
| `adoption_ignore` | permanent *ignore* decisions — append-only | a human, one at a time |
| `entity_link` (exists, W01) | every adopt/merge decision, with rule and confidence | scan (certain only) or human |

### The one finding so far that changed a design

Pure Sørensen–Dice scores `Review the 2026 budget` against `Review the 2027 budget` at **0.90** —
nineteen characters of agreement drown the one that is the entire difference. No threshold separates
that pair without rejecting every real near-match too. So rule 4 is now the threshold **and**
`titlesAgree` (`similarity.ts`), a word-level test: numbers must be identical, and a word unique to
one side needs a near-twin on the other unless it is a stop word. `fuzzyMatch` is the only door to
rule 4, so the threshold cannot be applied without it — and the near-miss corpus is refused even at
a threshold of zero.

### Decisions a resumed session should not re-litigate

- **The queue holds only adoptable kinds** (initiative, project, key result, ritual). A loose task,
  a principle and a signal are *counted* and reported, never queued: nobody works a queue of four
  thousand, so nobody works the queue. `queue.test.ts` pins this against a 4 000-object corpus.
- **`minimumSubtasks` is 2, not 1.** One subtask is how people write themselves a note.
- **An ambiguous match is not a match**, at every rule including fuzzy ties.
- **An object with no area matches only a target with no area.** "Unknown" is not a wildcard.
- **API scope:** the brief's *Files you may touch* predates W05, which already landed
  `GET /adoption` (the ledger) and `POST /adoption/decisions` (bind to an existing entity = *merge*).
  The queue screen additionally needs *list candidates*, *adopt* (create a prisme entity with
  `origin = adopted` **and** link it) and *ignore*. Those three routes go in `apps/api`, which is
  outside the brief's list — a deliberate, recorded departure, because a queue with no way to read
  or decide it is not a queue.
